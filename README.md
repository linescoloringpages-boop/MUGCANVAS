# Dealora

Public coupon site: Next.js (App Router) + Supabase (auth, Postgres with Row Level Security, storage) + PayPal one-time membership.

- Hebrew setup guide: `SETUP-HE.md`
- Database and security rules: `supabase/schema.sql`
- Environment variables: `.env.example`

```
npm install
npm run dev
```

Not run end to end by the author (no package install was possible when it was written). Follow the test checklist in `SETUP-HE.md` step 8 before taking real payments.
